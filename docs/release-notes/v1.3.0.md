## おもいでクローゼット 1.3.0（versionCode 4）

子供の小さくなった服・アクセサリー・おもちゃを写真で残し、スマホのクローゼットとして眺めるAndroidアプリです。
このリリースは、前開発スレッドで配布した署名済みAPKを**そのままのバイト列で**公開したものです（再ビルドなし）。

### 主な機能（1.3.0時点）
- 撮影／写真選択 → 背景切り抜き（端末内ML Kit＋手動補正）→ 種類・色などを登録（Gemini分類は任意、手入力で修正可）
- 上段トップス（左→右）／下段ボトムス（右→左）が独立して流れる2段クローゼット、小物棚のクロスフェード
- 家族の顔写真と複数所有者、上下セットの相互リンク、任意の裏面（縦スワイプで裏返し）、着用写真（最大50枚・説明付き）
- Google Driveフォルダ経由の複数端末統合、写真を埋め込んだオフライン閲覧用HTMLを含むバックアップZIP
- Daydream（スクリーンセーバー）とホーム画面ウィジェット

### インストール
- Android 8.0以降。`omoide-closet-1.3.0.apk` をダウンロードし、「提供元不明のアプリ」を許可してインストールします。
- 既に1.3.0以前を入れている端末では、同じ署名なので上書き更新できます。
- 署名証明書 SHA-256: `29bf75206503a4da8a01f2de381cd7dc31187c9520d20967b232c8004a4aaa0c`（リリースCIで `apksigner` 検証済み）

# この一式に含まれていないもの

## 署名秘密鍵とパスワード

配布用のsigning/omoide-closet.jksは、保存済みのソースZIPに元々含まれていない。以前の一時作業領域は自動整理されており、今回回収した保存成果物から元の鍵は回収できていない。鍵のパスワードや署名鍵ファイルを持っているという前提で次のAIが作業しないよう、明記する。

同梱のAPKは従来の署名付きのまま。だが、そのAPKと公開証明書の指紋から秘密鍵を取り出して新しいAPKに署名することはできない。元の鍵が別途保管されていれば同じ鍵で更新できる。見つからない場合、ユーザーの記録をバックアップしてから移行方法を決める必要がある。鍵の新規作成と同じ署名での更新を混同しない。

## 実際の服・顔・思い出データ

普段のスマホ内のSQLite、取り込んだ写真、家族の顔写真、下書きは、この開発用ZIPには含まれていない。今回はスマホに接続してそれらを回収していない。
実データを新しい環境へ渡す必要が出た場合は、アプリの「すべての思い出をバックアップ」で出したZIPを別途使う。サンプルHTMLは展示用イラストであり、実データのバックアップではない。

## APIキーとGoogle側の設定

実Geminiキー、Googleアクセストークン、Google Cloudプロジェクトの認証情報、アカウントのパスワードは含まれていない。キーはアプリ内から登録する既存設計であり、別のアプリの開発会話にあったキーをここへ転記・埋め込みしない。
Googleの初回設定説明書は含まれるが、実際のCloud登録が完了したことを示すものではない。

## 開発環境・履歴

SDK、JDK、Gradle依存キャッシュ、エミュレーターのディスク、過去の一時スクリーンショット、テストの生ログ、Git履歴は含まれていない。ソース、テストコード、設定指定、過去検証の説明書を同梱し、環境は再構築できるようにしてある。
1.0～1.2の別々の配布バイナリや当時の完全ソースは未収録。継続開発の基準は同梱の1.3.0とし、旧版経緯は履歴文書を参照する。

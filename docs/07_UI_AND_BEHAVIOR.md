# UIと操作の意味

原画：[手描き画面案](../references/8268.jpg)。プレビュー：[単独サンプルHTML](../releases/omoide-closet-sample-album.html)。

原画はユーザーが撮影して添付したノートの写真そのもの。再生成画像や後付けモックアップではない。現行の外観はサンプルHTMLとsource/omoide-closet/app/src/main/assets/を確認する。

## ホームの構成

上部：アプリ名と登録点数、家族とお気に入りのフィルター。
中央上：トップス用レール。左→右へ流し、独立した前／再生停止／次ボタンを置く。
中央下：ボトムス用レール。右→左へ流し、同様に独立操作する。
下部左：小物・おもちゃ・その他の展示棚。12秒ごとにクロスフェードし、タップで思い出へ。
下部右：写真を撮る／選ぶためのカメラ＋ボタン。
最下部：ホーム、検索、設定。

## ジェスチャー

| 操作 | 意味 |
| --- | --- |
| 各レールを横へスワイプ | その段だけを動かす |
| 裏面のある服を縦へスワイプ | ハンガーを裏返す。もう1段の水平位置は動かさない |
| 品物をタップ | 写真と思い出の詳細を開く |
| 詳細の表／裏ボタン | 縦スワイプの代替手段 |
| 顔をタップ | 所有者を選択・解除。複数人を選べる |
| 関連写真をタップ | 写真を大きく見て説明を読む |
| 関連アイテムをタップ | セット相手の詳細へ移る |

裏面のない品物に縦スワイプしても写真を失わない。登録画面で裏面・関連品・家族を未選択のまま保存できる簡単さを保つ。

## 登録の順序

家族を顔で選ぶ（任意・複数可）→撮影か写真選択→表の切り抜きと分類→必要な手修正→必要なら裏面・着用写真・関連セットを添える→保存。
パジャマは上と下を別々に登録し、配置をtop/bottomに指定してから関連付ける。

## 表示用と管理用の違い

検索タブは品物の一覧と検索。設定では家族、AI、表示速度、Daydream・ウィジェット、Drive、バックアップ、ごみ箱を扱う。
スマホの小さい画面でも、保存や撮影のボタンがナビの下に隠れないことを確認する。新しい機能を追加する時も、家族選択や裏面登録を強制して登録手順を重くしない。

## 1. 最初の依頼

```text
子供の受験が一段落するので家の中を断捨離しようと思います
子供の小さい時の服を捨てているものになるのですが名残惜しいので
思い入れのある服を写真に撮ろうと思います
そこで APK アプリを作って欲しいのですが
子供の服の写真を撮ったら
AI で それが ズボン なのか シャツなのか ワンピースなのか スカートなのか といった具合に 認識してデータベース化してもらうことと
その服だけを背景除去して切り出して
スマホの画面をクローゼットに見立てて ハンガーに吊るされた状態でランダムに右から左へ流れてくるようなアニメーションが表示される スワイプすることもできる そんなアプリを作ってもらえませんか
```

## 5. セット・裏面・着用写真・顔・複数所有者

```text
とってもいい感じです
服によっては パジャマのように 上下がセットになっている場合があるのでその場合は 関連アイテムとして 紐付けられるようにできたらいいかなと思います
また服によっては 背中に模様があって思っては 白いやつとかもあるので 裏面も登録できたらハンガーをスワイプなどして ひっくり返すようなジェスチャーで 裏面が見れたりとかどうでしょうか もちろん 多くの場合は裏面まで登録すると大変なので表のみでも OKにするんですけど
あと関連する写真 来ているところとか も添付できるようにできたらいいなと思います
家族を選択するわけですが 顔写真を登録しておいて 顔をタップすることで取り込みの時に選べたら それもいいなと思います
さらに うちは姉妹なので上の子も下の子も着てる場合があるので所有者は 複数 登録できたらいいなと思います
```

音声入力と思われる「思っては」「来ているところ」も原文のまま収録した。文脈では「表は」「着ているところ」として要求を整理している。

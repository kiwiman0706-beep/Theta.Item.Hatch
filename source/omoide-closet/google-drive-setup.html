おもいでクローゼット 1.3.0

家族の思い出を、
同じDriveフォルダで。

Google接続には、最初にGoogle CloudでこのAPKを登録します。家族で使う場合も、登録は1つのプロジェクトで行えます。

GoogleアカウントとGoogle Play開発者サービスが使えるAndroid端末で利用します。初回設定後、アプリの再ビルドやクライアントシークレットの入力は不要です。このAPKのGoogle登録と実際のログイン・Drive通信はまだ実施していません。

01 · Google Cloud

プロジェクトとDrive APIを準備

  1. Google Cloud Consoleを開き、個人用のプロジェクトを作成・選択します。
  2. 「APIとサービス」→「ライブラリ」で Google Drive API を検索し、有効にします。Drive APIの画面を開く
02 · Google Auth Platform

自分と家族をテストユーザーに追加

  1. 「Google Auth Platform」→「ブランディング（Branding）」から設定を開始します。アプリ名は「おもいでクローゼット」、連絡先はご自身のメールアドレスにします。
  2. 対象（Audience）を 外部（External） にし、公開ステータスは テスト（Testing） にします。
  3. 「テストユーザー（Test users）」に、利用するGoogleアカウントをすべて追加します。
  4. 「データアクセス（Data Access）」→「スコープを追加または削除」で、下のDrive権限を登録・保存します。
https://www.googleapis.com/auth/drive

Googleの許可画面ではDrive全体へのアクセスになります。既存・共有フォルダをURLで指定するため、この版では上記の権限を使います。アプリは選択したフォルダ内の同期ファイルを読み書きし、Driveのアカウント情報で接続中のメールアドレスを確認します。

個人・家族のテスト利用を想定した版です。一般公開する場合はGoogleの審査や、ファイル選択による権限の限定を含めて別途対応が必要です。

03 · Android OAuthクライアント

このAPKの署名を登録

「クライアント（Clients）」→「クライアントを作成」で、種類を Android にします。名前は任意です。パッケージ名とSHA-1に以下を登録します。

パッケージ名
jp.omoide.closet
配布APKの署名証明書 SHA-1
E6:C0:02:3F:71:1E:23:5D:18:97:A5:ED:8E:74:BD:D9:C1:5F:6E:35

Androidクライアントはパッケージ名と署名でAPKを識別します。作成されたクライアントIDをアプリに入力する欄はありません。ソースから別の署名でビルドした場合は、その署名のSHA-1を追加登録します。上の値は配布用APKの値です。

04 · アプリ

最初の端末でフォルダを作る

  1. APKを上書きで更新し、設定の「Google Driveで思い出を共有」→「Googleに接続する」を押します。
  2. テストユーザーに登録したGoogleアカウントを選び、Driveへのアクセスを許可します。
  3. 「新しい同期フォルダを作る」を押します。保存済みの写真と記録がアップロードされます。
  4. 表示された「ほかの端末で使うフォルダURL」をコピーします。初回同期が終わってから次の端末をつなぎます。
05 · ほかの端末

同じフォルダへ接続して統合

同じGoogleアカウントを使う端末は、そのまま接続できます。別のGoogleアカウントを使う場合は、Driveでそのフォルダを相手に 編集者 として共有し、そのアカウントもテストユーザーへ追加します。

  1. もう1台のアプリでも「Googleに接続する」を押します。
  2. 「共有フォルダのURL・ID」に先ほどのURLを貼り付け、「このフォルダを使って統合」を押します。
  3. この端末に既にある記録も、共有フォルダの記録も両方残して統合します。同じIDの記録を同時に編集した場合は「同時編集の別版」として保存します。

自動同期は、アプリを開いた時・記録した時・表示中の約5分ごとです。閉じている間の常時同期は行いません。すぐ反映したい時は、両方の端末で「今すぐ同期・統合」を押してください。

下書き・Gemini APIキー・Googleアクセストークンは同期しません。別々に撮影・登録した写真は別の記録になります。ごみ箱への移動・復元・お気に入りも同期します。変更履歴と写真をDriveに保存するため、フォルダの中の同期用ファイルを個別に削除しないでください。

HTML付きバックアップの見方

設定→「すべての思い出をバックアップ」でZIPを保存します。ZIPを展開し、closet.html をブラウザで開きます。

  • 写真・画面・操作を1つのHTMLに埋め込み、ネット接続なしで閲覧できます。
  • 上下の独立スワイプ、再生・停止、シャッフル、子供別・お気に入りの絞り込み、検索、思い出の詳細を使えます。
  • HTMLは書き出した時点の閲覧用アルバムです。撮影・編集・最新データの同期はAndroidアプリで行います。ごみ箱の品物はHTMLには表示せず、復元用データには含めます。
  • Driveのプレビューで動かない場合は、HTMLをダウンロードしてブラウザで開いてください。写真を含むファイルなので、渡す相手を選んで共有してください。

接続できない時

  • 「アプリ登録を確認」：Androidクライアントのパッケージ名・SHA-1、Drive APIの有効化、テストユーザーの登録を確認します。
  • 「権限を確認」：フォルダの共有が「編集者」であること、Driveの空き容量、登録したスコープを確認します。
  • 「再接続が必要」：アプリの「今すぐ同期・統合」で許可画面を開き直します。Googleのテスト状態では再認可が必要になることがあります。
  • 通信エラー：写真と記録は端末に残ります。同じフォルダに対して再同期します。
